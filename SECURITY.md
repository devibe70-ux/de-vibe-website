# Security Policy & Vulnerability Disclosure

De Vibe Engineering treats software security as a critical priority.

## Reporting a Vulnerability
Please do NOT open public GitHub issues or public support tickets for security vulnerabilities.

Email security reports directly to: **help@devibestudio.com**

- **Response SLA:** Acknowledgment within 24 hours.
- **Triage SLA:** Initial assessment & remediation plan within 72 hours.
- **Safe Harbor:** De Vibe will not pursue legal action against security researchers who report vulnerabilities in good faith and adhere to responsible disclosure principles.
